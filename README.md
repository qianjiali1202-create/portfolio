# 钱佳丽 · UX 设计师作品集

一个从零搭建的 UX 作品集，同一套内容同时产出**网页版**和 **PDF 版**。

## 内容结构

首页给出定位与项目列表，每个项目是一页独立案例，统一按六段式撰写：
**问题 → 调研 → 洞察 → 策略 → 方案 → 结果与反思**。

六段式的好处是横向可比——招聘方看完三个案例，能清楚看出你在不同类型问题上的判断方式。

## 制作方式

- **纯静态**：HTML + CSS，没有框架、没有构建步骤，双击 `index.html` 就能打开
- **一份内容两种产出**：样式表里写了打印规则，浏览器 `⌘P` → 「存储为 PDF」即为一本作品集册子，导航和页脚会自动隐藏、卡片不会跨页断开
- **视觉统一**：所有颜色、字号、间距、圆角都来自 `assets/style.css` 顶部的一组设计变量，改一处全站生效

## 目录

```
portfolio/
├── index.html          首页：定位 + 项目列表 + 关于我
├── case-01.html        案例 01（完整六段式）
├── assets/style.css    全站样式：设计变量 + 布局 + 打印规则
└── README.md           本文件
```

## 本地预览

双击 `index.html` 即可。导出 PDF 时在打印窗口里选择「存储为 PDF」，纸张建议 A4、边距设为默认。
