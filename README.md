## 怎么用

**看效果**：双击 `index.html`，用浏览器打开。

**导出 PDF**：在浏览器里按 `⌘P`，目标选「存储为 PDF」。
导航栏和页脚会自动隐藏、卡片自动不跨页——**网站和 PDF 是同一套内容，不用维护两份**。

**加一个新案例**：复制 `case-01.html`，改名为 `case-02.html`，替换里面的文字和图片。样式会自动套用。
